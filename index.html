Отчёт: HTTP-запросы CLI и GUI

1. GET и POST через netcat

Команда GET:

printf 'GET /get HTTP/1.1\r\nHost: httpbin.org\r\nConnection: close\r\n\r\n' | nc httpbin.org 80

Команда POST:

printf 'POST /post HTTP/1.1\r\nHost: httpbin.org\r\nContent-Type: application/json\r\nContent-Length: 41\r\nConnection: close\r\n\r\n{"book":"Чапаев и Пустота","price":100}' | nc httpbin.org 80

2. Запросы через cURL

Команда GET:

curl -v http://httpbin.org/get

Команда POST:

curl -X POST http://httpbin.org/post \ -H "Content-Type: application/json" \ -d '{"book":"Чапаев и Пустота","price":100}'
